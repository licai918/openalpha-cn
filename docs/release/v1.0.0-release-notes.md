# OpenAlpha CN v1.0.0

首个稳定公开版本，面向中国 A 股的本地优先、证据驱动投研。

## 主要能力

- 四时间戳 Point-in-Time 证据与内容寻址；
- 合法安全的文件、Tushare BYOT 和可选 AKShare 接入；
- A 股事件证据、多智能体研究、风险、显式弃权和不可变决策账本；
- 实时/回放/回测共用核心路径；
- A 股执行约束、300 事件冻结回放、未来结果验证与归因；
- REST、Python SDK、CLI、响应式 Web；
- 非 root Docker Compose 和持久卷恢复验证；
- Windows/Linux CI、安全审计和 100% 功能去向台账。

## 安装

```bash
git clone --branch v1.0.0 https://github.com/ss8875/openalpha-cn.git
cd openalpha-cn
docker compose -f deploy/compose.yml up -d --build
```

访问 `http://127.0.0.1:8000`。

## 已知边界

- 不连接实盘券商；
- 不提供或转售商业原始行情；
- 不保证研究结果盈利；
- 默认本地部署没有多用户认证，不能裸露到公网；
- 组合现金/持仓逐日核算和图形化 Agent Flow Builder 延后。
