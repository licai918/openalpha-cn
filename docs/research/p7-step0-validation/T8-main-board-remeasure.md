## 0. 结论

1. **宇宙明显变小，被过滤的主要是次新，不是 ST。** 主板每个信号日有成交的证券 2,301 / 2,843 / 3,109 只（最小 / 中位 / 最大），可投资（成交额前 70%）1,611 / 1,990 / 2,176 只；探索期口径（主板 + 创业板、无过滤）的可投资集合是 1,765 / 2,487 / 2,840 只，约大 25%。可投资集合里 ST（名称 ∪ 主板 5% 带宽 ∪ `pending_at`）中位 25 只（12–83），次新（< 250 个交易日）中位 116 只（66–264），两者加退市整理期与无上市行合计占 4.1% / 7.5% / 16.0%。再剔除这些名字、并要求四个因子值齐全、前向两根 K 线齐全后，账簿可抽的可投资集合平均 1,737，幸存者 1,062 / 1,502 / 1,626 只（**平均 1,390，对探索期口径的 1,898 少 27%**），入选候选平均 1,042 对 1,423。（§2）
2. **输家尾部模式在仅主板上仍然成立，只是略弱。** 四因子合成分的 20 日前向秩 IC：主板 + 过滤 +0.106（t 5.5），探索期口径 +0.113（t 5.6）；最差十分位超额 −1.48%/20 日（t −4.0）对 −1.75%（t −3.9）；剔除最差 2 个十分位的幸存者毛超额 +2.75%/年（se 0.85）对 +3.87%/年（se 1.00），配对差 −1.1pp（配对 se 0.8），其中换板块约 −0.7pp、加 ST/次新过滤约 −0.4pp，都在噪声之内。"早先的输家尾部主要是创业板"这个假设**没有得到支持**：创业板在最差两个十分位里占名字的 38.3%（它在可投资集合里占 22.5%，是 1.7 倍），但只承担该尾部超额亏损的 29%；板内 IC 几乎一样（主板 +0.1115、创业板 +0.1141）。（§3）
3. **N=10 粘性账簿（日期盐哈希，600 个种子）在主板 + 过滤上的样本内数字低一点、波动小一点。** 净超额 +6.33%（A）/ +6.06%（B），跟踪误差 11.70%，单年超额 p10·中位·p90 −6.9·+6.7·+22.4% / −7.2·+6.5·+22.0%，单年跑输概率 27%，每期换出 0.05；同一 harness 下复现的探索期口径是 +7.41% / 12.77% / −6.4·+7.7·+23.9% / 24%（同一脚本里的 `random.sample` 臂用 600 个种子逐位复现了 T1 §3.2 的 `R1` 行）。降幅 1.1–1.4pp 的分解：换板块 −0.5pp（抽样 se 1.2）、过滤 −0.7 ～ −1.0pp（抽样 se 0.6；幸存者里 ST 的样本内超额是 +17%/年、次新是 −15%/年，方向一致，但没有在模拟里单独分解，两者都不稳）。**设计 §3 的预期里，净超额约保留 80–85%，跟踪误差反而低约 1.1pp，单年跑输概率落在 24–31% 区间内。**（§4、§5.1）
4. **流动性的 A / B 两种读法没有可检出差别，不据收益选择。** A（对主板所有有成交的证券切 30%）与 B（只对通过静态原因的证券切）：净超额差 −0.27pp（抽样 se 0.18），过滤关闭时差 −0.01pp；流动性出场占全部出场的 48.5% 对 48.8%；持仓被流动性线翻转的概率 2.55% 对 2.60%；切线因总体构成变化相对继续存在的名字移动的幅度（过滤开）A 均值 0.17、最大 0.60，B 均值 0.15、最大 0.67 个名次百分点。（§4.3–§4.4）
5. **账簿的出场大约一半由流动性线引起，不是输家线。** 10 只账簿每 20 个交易日平均换出 0.5 只；出场原因（主板各变体）：流动性 48.5–52.0%、输家线 35.0–39.2%、无数据 11.8–13.1%、过滤（ST/次新）0–0.5%。其中"自身 20 日成交额变动不到 10% 却被切掉"只占流动性出场的约 7%（变动不到 20%：约 15%），即**边界漂移**不是主因，主因是名字自己的成交额变化。每日筛选看到的穿越比 20 个交易日取样多约 40%（每期 3.51% 对 2.45%）。持仓免于流动性线的机械探针：出场减半（0.52 → 0.29 只/期），净超额差 −0.45pp（抽样 se 1.2），这是对"`illiquid` 是否强制出场"那个待用户确认选择的量，不是推荐。（§4.4–§4.6）
6. **研究期最后一年模式明显减弱，且无法在样本外检验。** 主板 + 过滤、2021 年的 10 个信号日：IC +0.037、最差十分位 −0.03%、幸存者毛超额 −1.9%/年，账簿样本内 −11.6%/年；探索期口径同年 IC 也只有 +0.039。10 个日期的均值比总体均值低约 1.5 个标准误，不显著，但 2022 年起的窗口已被此前的预登记花掉，这里没有办法再看。（§3.3、§4.5）
7. **要立即上报的几项**见 §5.2（预登记的预期数字要换成主板 + 过滤的口径；`illiquid` 出场的量级；2021 年减弱；内核默认板块；方案 B 的基线与训练样本）。

## 1. 设定

### 1.1 窗口与护栏

- 信号日：与 T1 相同的 59 个（`days` 中 2017-01-03 … 2021-10-29 每隔 20 个交易日取一个；最后一个是 2021-10-14，其前向腿到 2021-11-12，与 T1 一样）。20 日持有、次日收盘买入，年化因子 244/20。
- 只读：价格 / 成交额 `daily`（2016–2021 年分区）、`adj_factor`（2013–2021）、`stk_limit`（2016–2021）、`trade_cal`（2013…2021-10-31）、`stock_basic`（1990–2021，`lifecycle_date ≤ 2021-10-31`）、`namechange`（公告年 2013–2021，`announcement_date ≤ 2021-10-31`）、四个因子的 `processed` 档（2017–2021，只取 59 个信号日）。脚本用内存 DuckDB 读 parquet，不写盘、不联网、不读 `.env`、不经 `PanelStore` / `catalog.duckdb`；`assert days[-1] <= "2021-12-31"` 与 T1 相同（`daily` 的 2021 年分区含 11–12 月，仅最后一个信号日的前向腿用到 2021-11-12）。
- **从仓库导入的只有** `openalpha_cn.domain.name_history`（名称语法与 `NameHistory.announced_by(d).risk_warning_on(d)` / `pending_at(d)`，与 T3 一致）。**筛选与粘性策略在脚本里用 numpy 重新实现**，口径与 T1 的 `stratified.py` 一致（幸存者 = 可投资集合剔除合成分最差 2 个十分位；入选 = 合成分在幸存者 25 分位及以上；已持有的名字只在掉出幸存集合或无数据时才被换掉；抽取 = `sha256(f"{seed}|{session}|{code}")` 升序，`session` 为信号日在交易日序列中的序号）。没有导入 `step0-core-reference/.../survivor_*.py`：内核按单个信号日工作，带 20 日冷却与每日 2 笔上限，而 T1 的 20 个交易日一期的模拟没有这两样；二者的差别在 §7 列出。

### 1.3 与 T1 的核对

同一份脚本在**主板 + 创业板、T1 口径、过滤关**的单元格里复现了早先的数字：随机抽样 `random.sample` 臂（600 个种子）净超额 +7.27%（se 0.21）、跟踪误差 12.86%（se 0.07）、单年 −6.7·+7.5·+23.8%、跑输概率 25%，与 `T1-stratified-vs-random.md` §3.2 的 `R1` 行**逐位一致**；日期盐哈希臂 +7.41%（T1 §5 用"日期"当盐得到 +7.61%，se 0.22，差 0.2pp，在噪声内——这里用交易日序号当盐）；与日期无关的哈希队列 +6.19%（T1 §5：+5.96%，换了哈希串，同样在噪声内）。另在原脚本上重跑 `BOARDS=main_chinext SEEDS=60 MECH=0 stratified.py`，`R1` 仍是 +7.75% / 12.70%。不同 `PYTHONHASHSEED`（0 与 7）下本脚本的输出逐字一致。

### 1.4 噪声的两个来源

- **蒙特卡洛**（种子）：600 个种子下净超额的标准误约 0.20–0.22pp，跟踪误差约 0.07pp。
- **时期抽样**：把 59 个时期当作一个样本，种子平均后的逐期超额的时间序列标准误（每期不重叠，直接取 `std/√59 × 12.2`）：**各变体的净超额水平约 2.8–3.4pp**。配对差异（同一批时期）的抽样 se 小得多（0.1–1.4pp，取决于两个变体有多相像）。下面凡写"（抽样 se …）"的都是这个。**这两种标准误都不覆盖"阈值是事后选的"这个偏差。**

## 6. 对方案 A / B / C 的影响

- **方案 A（智能体否决层，加在资格层）。** 否决层作用于主板 + 过滤后的幸存者（日均约 1,390 只，不是 1,898）。ST / 次新过滤把可投资集合缩小 4–16%（中位 7.5%），所以否决层可以与它们并列写进同一张资格原因表，不需要改结构。因为 A/B 两种流动性总体读法没有区别，一个新增的否决原因码是否进入流动性总体也**不会**移动切线（漂移最大 0.8 个名次百分点）——可以按实现最简单的写法。N=10 的跟踪误差仍约 11.7%，组合层结果仍不能当证据。
- **方案 B（证据变特征，并入同一模型）。** (1) **基线要换**：比较基线必须是**同一代码路径、同一宇宙（主板 + 过滤）、同一随机源（日期盐哈希）**的随机臂，样本内是 +6.1 ～ +6.3%，不是 +7.4% / +7.7%；两者相差 1.1–1.4pp，量级与 B 的预期增量相当（T1 §7 已经指出这类基线错位）。(2) **训练样本**：必须施加同一套资格（T3 §8）并只含主板：创业板在最差两个十分位里占名字 38%，一个池化训练的模型会把大量学习量花在账户永远买不到的名字上；但本文没有发现池化因子在两个板块上行为不同（板内 IC +0.1115 对 +0.1141），所以这是样本量与适用范围的问题，不是方向问题。主板可投资集合比池化口径少约 20%，加上过滤与数据要求后幸存者少约 27%，训练样本相应减少。
- **方案 C（智能体前向登记，幸存者内部的增量 IC）。** (1) 评估域（幸存者内部）日均 1,390 只，比探索期口径少 27%，每个日期的截面更小，增量 IC 的估计更吵；但 IC 的水平（+0.106 对 +0.113，配对 se 0.010）与日期间标准差（约 0.15）没有变，P7 文档 §3.6 的功效表（IC 0.05 需要约 32 个不重叠的 20 日期）**不用改**。(2) 登记范围（"每个可投资证券一个 score"）日均约 1,740 行，比 2,370 少，运行时间只会更短。(3) 登记时的宇宙定义（板块、ST 的并集规则、`UNKNOWN` 名称状态的处置、`NO_LISTING_ROW`）仍要随 `V2-P7-006` 一起冻结。

## 7. 局限

- **样本内、事后、单一窗口。** 59 个信号日，阈值是此前事后选的；两种标准误都不含这个偏差。本文**没有**改任何阈值，也没有拿其中任何一个数字挑规则。研究期已被此前的探索（四因子、T1、T3）反复使用。
- **节奏是每 20 个交易日一次**，没有设计中的每日替换上限（≤ 2 笔）、20 日冷却、订单生命周期、T+1、整手、涨跌停、停牌，首次建仓不计成本。每日节奏下的流动性穿越更多（§4.6，约 1.4 倍），而 T+1、涨停买不进、跌停卖不出会改变出场的实际成交。模拟里的 0.5 只/期不能直接搬到真实日流程。
- **基准**是同一变体自己的可投资等权，不是中证 500；"超额"不是收益声称。样本期里这个基准本身年化几乎为 0 到 +1.1%。
- **总体 A 与内核不完全相同**：内核的 `screen()` 对"主板所有证券"切流动性线，含当天停牌、零成交的名字；本文 A 只含当天有 K 线的名字。缺的这部分（20 日窗口里有 K 线、当天没有）每日 1 / 10 / 94 只（最小 / 中位 / 最大），占有成交证券的 0.0% / 0.3% / 3.7%，最大值在 2017 年初；按本文的名次漂移衡量，对线的影响小于 1 个百分点（中位日只有 0.3 个）。B 与内核的逐位对应没有核对过。
- **前向齐全约定**：不满足"次日与 20 日后都有 K 线"的名字被排除出总体（小的前视，每日约 16 只；`FILL=1` 的敏感性见 §4.7，结论不变）。因子值齐全的要求把长期停牌后复牌的名字也排除了。
- **ST 来源与 T3 一致**：名称 ∪ 主板 5% 带宽 ∪ `pending_at`，`UNKNOWN`（无记录 / 有记录但当日无生效记录）按普通处理，没有读取"当天晚上才公告"的名称（`available_time` 定在公告日 0 点是乐观下界，T3 §9.3）。`pending_at` 在这 59 个日期上没有触发。"此后才变 ST"的持仓风险只在下一个信号日才看到。
- **次新**按开市日口径与 250 个交易日；无上市行（0–2 只/日，代码迁移的旧代码）判不合格；日历起点已断言早于首个信号日至少 250 个交易日。
- **合成分的标准化总体**：`processed` 档的横截面标准化是在建库时的总体上做的（是否含创业板 / 科创板 / 北交所本文没有核对）；仅主板上合成分只用来排序，影响应有限，但 IC 的绝对水平可能受此影响。
- **时期之间的依赖**：59 个时期不重叠，但市场状态（2018 熊市、2021 风格切换）把它们联系在一起；单年超额窗口是重叠的滑动窗口（48 个窗口），p10 / p90 的真实不确定性比表里大。
- **账簿位置与每日筛选核对**（§4.3 末、§4.6(ii)）只用前 100 个种子的账簿；§4.4 的翻转计数用全部 600 个种子。计数在种子间高度相关（同样的名字被反复抽到），只看比例。
- 本文的工作分支先快进到 `docs/v2-p7-005-main-board-only`（`f348e7e`），报告放在 T1 / T3 同一目录；报告之外没有改任何仓库源文件。
